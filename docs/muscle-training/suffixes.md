Numbers in the game are shortened with suffixes. Here is every suffix, from smallest to largest.

## Class I (K – Dc)

| Suffix | Name |
|---|---|
| K | Thousand |
| M | Million |
| B | Billion |
| T | Trillion |
| Qa | Quadrillion |
| Qi | Quintillion |
| Sx | Sextillion |
| Sp | Septillion |
| Oc | Octillion |
| No | Nonillion |
| Dc | Decillion |
